- 每页 6x9，前 45 格持久化存储，最后一行提供翻页、余额、状态与扩展按钮。
- 默认免费第 1 页，支付货币解锁第 2 页。配置已生成在 `run/config/qiandao-cloud-storage.json`：
  ```json
  { "expansionCost": 100, "maxPages": 2 }
  ```
