近期优化更新日志

1. 云仓会话改为原版容器交互与独立会话镜像，支持 Shift 点击、拖拽、双击收集、数字键交换、丢弃等原版操作。

2. 云仓使用检查点、关闭、翻页、断线与停服统一事务提交；提交失败会冻结会话并保留 journal 恢复证据。

3. 加固云仓恢复状态机：`COMMITTED`、`ROLLED_BACK`、`QUARANTINED` 均为不可重复转换的终态；启动恢复仅处理 `PREPARED` 记录。

4. 增加云仓崩溃恢复测试，覆盖旧页面保留、页面已写入但未提交、已提交事务重启等场景。

5. 修复云仓控制栏物品可被 Shift 点击误存入的问题，并补齐快速转移槽位边界测试。

6. 云仓自动检查点统一使用世界 `gameTime`，避免服务器重启后因 `tickCount` 归零而长期不保存。

7. 修复断线或停服已成功提交后，延迟菜单关闭回调重复提交并误标记失败的问题。

8. 修复模块降级、禁用、权限变化时云仓会话可能跳过收尾提交的问题；现在会继续提交，或保留锁定会话与恢复证据。

9. 新增统一操作账本诊断：
   - `/omnitools diagnose`
   - `/omnitools diagnose operation <操作ID>`
   可查看云仓、技能经验、商店与奖励账本状态，且诊断全程只读。

10. 云仓保留专用人工恢复命令：
    `/omnitools storage recovery list|inspect|resolve`
    管理员可按操作 ID 查看并执行提交或回滚。

11. 新增模块故障隔离与健康状态：模块异常会进入 `DEGRADED`，不再拖垮服务器；成功配置重载后恢复。

12. 新增统一结构化错误报告，记录模块、功能、玩家、操作 ID、状态、恢复动作与完整异常堆栈。

13. 增加模块级和玩家级资源预算；超限操作会在数据变更前拒绝，并记录预算原因。

14. 异步审计日志写入增强：运行时异常不会终止后台线程，支持重试、失败统计及无父目录日志路径。

15. 技能经验改为可恢复事务，支持 `PREPARED → COMMITTED`、启动恢复、操作 ID 去重与每秒合并刷盘。

16. 制造经验改为制作完成事件驱动，移除周期遍历全部物品注册表的主线程开销。

17. 新增技能诊断与事件路由回归测试，修复旧技能 ID 与 canonical ID 不一致导致经验不结算的问题。

验证结果：

- 云仓与模块健康专项测试通过。
- 内容校验无错误、无警告。
- 受管构建通过，已生成 `modmind-current-project.jar`。
- 隔离服务端启动并稳定运行 15 秒。
- `git diff --check` 通过。
