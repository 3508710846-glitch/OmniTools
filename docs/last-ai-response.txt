本次后续更新日志

1. 云端储存完成会话镜像重构，支持原版容器交互、Shift 点击、拖拽、双击、数字键交换与丢弃操作。  
2. 云端储存加入检查点、关闭、断线与停服事务提交；失败会冻结会话并保留 `PREPARED` 审计记录。  
3. 云端储存 journal 终态恢复逻辑加固，`COMMITTED`、`ROLLED_BACK`、`QUARANTINED` 不再被重复转换。  
4. 制造技能经验改为制作完成事件驱动，移除周期遍历全部物品注册表的主线程开销。  
5. 生命周期逻辑从主入口拆分至独立注册器，模块启动、恢复与停服清理更隔离。  
6. 新增独立 mcMMO 行为兼容层，支持 Mining、Woodcutting、Herbalism、Excavation、Swords、Axes、Archery、Acrobatics、Repair、Alchemy 十项技能。  
7. 增加 `/skills stats`、`/skills ability`，并补充旧专业树 ID 到新技能 ID 的兼容映射。  
8. 新增 `SkillHudService`：经验成功结算后显示单条合并 BossBar，升级显示标题、音效与 ActionBar；主动和被动技能反馈均由服务端控制。  
9. 修复 canonical 技能 ID 与旧配置树 ID 不匹配导致的不加经验问题。  
10. XP 结算改为可恢复事务：记录 `PREPARED` 前后快照、`COMMITTED` 终态与启动恢复链，防止重启时少发或重复发放。  
11. XP 事务改为每秒合并保存、停服强制刷写；每个经验请求必须携带稳定操作 ID。  
12. 新增 `/skills health` 管理员诊断，显示经验成功/拒绝数量、拒绝状态、来源分布与事务状态。  
13. 方块和击杀经验路由抽为独立组件并增加回归测试；未成熟作物不再提供农业经验。  
14. 补充技能事务、诊断、事件路由、连续事务恢复及恢复合并的自动化测试。  
15. 已完成内容校验、全量测试、受管构建与服务端稳定运行验证。
