# 备份与恢复

## 必须备份的内容

| 内容 | 位置 | 包含内容 |
| --- | --- | --- |
| 世界数据 | 服务端世界目录 | 签到、货币、在线时长、称号、成就、云存储、奖励账本、侧边栏偏好 |
| 配置 | `config/omnitools/` | 根开关、模块规则、命令菜单、归档和迁移备份 |

升级、修改奖励 ID、修改数据保留模式、切换模块或迁移服务器前，停止服务端后备份这两部分的同一时间点。

## 恢复

1. 停止服务端。
2. 将世界和 `config/omnitools/` 一起恢复到同一备份时间点。
3. 启动服务端，检查日志，再运行 `/omnitools diagnose`。

不要只恢复配置或只恢复世界：奖励事件与奖励 ID 必须对应，才能正确判断是否已发放。不要直接编辑 SavedData 文件；应恢复完整世界备份。

启用 `monthly_summary` 或 `archive` 前，系统会将签到数据归档到 `config/omnitools/archives/`。归档用于审计，不替代世界备份。

异常奖励请使用[奖励一致性指南](reward-consistency.md)中的 inspect、retry 和 resolve 工具处理。
