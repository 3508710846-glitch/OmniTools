# Mod idea

做一个签到mod，玩家可以通过指令打开签到GUI（这个GUI大小为5*9，前四行为签到日期格子，最后一行的中间显示当前玩家的头颅，玩家鼠标悬浮在上面可以看到今天是第几个签到的人、累计签到的天数、连续签到的天数）。
玩家可以点击当前日期的格子，完成签到
玩家点击日期槽位时，从服务器端校验槽位索引是否对应当前日期，并执行签到逻辑。如果当天已签到，显示附魔书；如果未签到，显示普通书。

## Project target

- Loader: fabric
- Minecraft: 1.21.11
- Namespace: qiandao

## Development request 2026/8/20 20:22:43

添加一个商店GUI，消费的是签到、在线送的货币。
商店的大小为6*9，前五行是商品，最后一行是功能行，有上一页、下一页、玩家头颅（鼠标浮在上面显示当前余额）。
商店卖的东西可以在配置文件内高度自定义，支持非常长的nbt物品，价格也可以在配置文件中自定义。
[
  {
    "index": 0,
    "item": "minecraft:diamond",
    "count": 1,
    "price": 20
    }
]
上面的这一段是一个示例代码
其中：
index：GUI 中的槽位编号（通常从 0 开始，即第一格）。

item：物品的 Minecraft 注册 ID（如钻石为 minecraft:diamond）。

count：单次购买获得的数量（这里为 1 个）。

price：购买所需货币数量（这里为 20）。

没有被编码的格子默认为空白或玻璃填充

如果商品超过45个（占满前五行），自动开启下一页。

## Development request 2026/8/21 10:03:54

添加新功能——称号系统。
1.玩家发送聊天消息时，显示在名字前面，例如 [地质学家] 玩家名: 大家好。
称号支持用颜色代码来表示，例如§7[§r地质学家§7] §r玩家名
2.按 Tab 键显示的玩家列表中，在玩家名字后面显示称号。
3.玩家头顶的 NameTag，在称号前加前缀，如 [建筑师] 玩家名
称号分为普通、稀有和传说三个等级
普通称号仅在 Chat 前缀显示，稀有称号在Chat + Tab 列表显示
传说称号在Chat + Tab + 头顶显示。
玩家可以通过指令打开GUI菜单，展示玩家已解锁的所有称号，玩家在此处选择当前佩戴的称号（点击切换）。
管理员可以在游戏内通过指令为某位玩家添加称号。
服主可以在配置文件内查看所有玩家已拥有的称号、添加或删除玩家称号。
通过这两种方式获取的称号，默认不佩戴，需玩家手动佩戴。。
假如删除玩家某个称号后，玩家称号数量为0时，不显示任何称号
